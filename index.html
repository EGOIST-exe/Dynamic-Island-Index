THE LITTLE DETAILS

Good to know.

Why does the installer ask about a certificate?

This release uses a development signing certificate, rather than a publicly trusted publisher certificate. The setup explains this and asks for your consent before adding its public certificate to Windows Trusted People, with administrator approval. Review the prompt before installing.

Does it only work with Spotify?

No. Media controls use Windows media sessions, so other players and browser media can work too when they expose those controls. Online synced lyrics are optional and use LRCLIB.

Can it display every Discord message and call?

Not every one. The optional Discord connection can receive supported client events and learn reported private chats. Complete DM discovery and reliable private-call ringing detection are not available through the current connection. Accept/reject controls use Discord keyboard shortcuts.

Can it start quietly with Windows?

Yes. Autostart runs the app in the background. Open Settings from its tray icon whenever you need them. You can change startup behavior in the app.
